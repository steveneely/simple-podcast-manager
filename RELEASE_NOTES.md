# Simple Podcast Manager v1.9.0

- Automatically prepares the latest 1, 2, 3, or all new episodes after feed refreshes.
- Sets a first-refresh baseline so existing feed backlogs are not downloaded.
- Lets each show opt out of automatic downloads or be disabled entirely.
- Keeps device sync manual so every copy and deletion can still be reviewed.
- Groups Refresh, Edit, and Remove controls under the selected show.
